How ChangeHover Works

Learn how to implement and customize animations in your projects

Include the Library

Add the ChangeHover CSS file to your project using either CDN or local installation:

<!-- Via CDN -->
<link rel="stylesheet" href="https://cdn.changehover.com/v1/changehover.min.css">

<!-- Or locally -->
<link rel="stylesheet" href="path/to/changehover.css">

That's it! No JavaScript required. The library is pure CSS.

Apply Animations with Attributes

Add hover animations to any element by simply including a custom hover: attribute:

<div hover:ch-bounce>
  Hover over me!
</div>
Hover Me

The animation will automatically trigger when users hover over the element.

Customize Animation Properties

Override default animation properties using CSS variables:

<style>
  .my-element {
    --ch-duration: 0.8s; /* Animation duration */
    --ch-delay: 0.2s;    /* Animation delay */
    --ch-timing: ease-out; /* Timing function */
  }
</style>

<div class="my-element" hover:ch-pulse>
  Custom Animation
</div>

Available Custom Properties

  • --ch-duration: Animation duration (default: 0.5s)
  • --ch-delay: Animation delay (default: 0s)
  • --ch-timing: Timing function (default: ease)
  • --ch-repeat: Animation iteration count (default: 1)
  • --ch-accent: Primary color for gradient effects

Combine with Your Existing Styles

ChangeHover works seamlessly with your existing CSS classes and frameworks:

<button class="btn btn-primary" hover:ch-pulse-grow>
  Animated Button
</button>

<div class="card" hover:ch-float>
  <h3>Floating Card</h3>
  <p>Hover to see the effect</p>
</div>

Advanced Usage

For more complex animations, you can chain multiple effects or use helper elements:

<!-- Chaining multiple animations -->
<div hover:ch-rotate hover:ch-pulse>
  Rotating Pulse Effect
</div>

<!-- Using helper elements for background effects -->
<div hover:ch-bg-ltr style="position: relative;">
  Background Animation
  <div class="ch-animation-helper"></div>
</div>

Performance Tips

  • Use transform and opacity properties for smoother animations
  • Avoid animating properties that trigger layout recalculations
  • Limit the number of simultaneous animations on mobile devices
  • Use will-change property for elements you know will animate
