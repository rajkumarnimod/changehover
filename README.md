# ChangeHover - CSS Hover Animation Library

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A lightweight, dependency-free CSS library with 150+ ready-to-use hover animations for buttons, cards, text, and more. Just add attributes - no JavaScript required!

## ✨ Features

- **150+ Hover Effects** - From subtle fades to vibrant text and border animations
- **Zero Dependencies** - Pure CSS, works with any framework
- **Tiny Size** - Under 12KB minified (all animations)
- **Mobile-Friendly** - Optimized for touch devices
- **Cross-Browser** - Works on Chrome, Firefox, Safari, Edge
- **Easy Implementation** - Just add `hover:ch-*` attributes

## 🚀 Installation

### CDN (Recommended)
```html
<!-- Full Library (all animations) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rajkumarnimod/changehover/dist/changehover.min.css">

<!-- Core Animations Only (94+ effects) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rajkumarnimod/changehover/dist/core.min.css">

<!-- Text Effects (19+ animations) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rajkumarnimod/changehover/dist/text.min.css">

<!-- Border Effects (9+ animations) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/rajkumarnimod/changehover/dist/borders.min.css">
```

---

## 💡 Basic Usage
- Add hover:ch-* attributes to any HTML element:
```html
<!-- Core Animation -->
<button hover:ch-bounce>Click Me</button>

<!-- Text Animation -->
<h2 hover:ch-text-gradient-flow>Animated Heading</h2>

<!-- Border Animation -->
<div hover:ch-border-ltr>
  <span class="ch-animation-helper"></span>
  Hover Card
</div>
```

## 🎨 Animation Categories

### Core Animations (94+)

**Fade/Grow**  
`hover:ch-fade`, `hover:ch-grow`
**Bounce/Pulse**  
`hover:ch-bounce`, `hover:ch-pulse`
**Rotations**  
`hover:ch-rotate`, `hover:ch-flip`
**Slides**  
`hover:ch-slideInUp`, `hover:ch-slideOutLeft`

_And 80+ more!_


### Text Effects (19+)

- `hover:ch-text-gradient-flow`
- `hover:ch-text-glitch`
- `hover:ch-text-wave`
- `hover:ch-text-neon`
- `hover:ch-text-bounce`

_And 10+ more!_


### Border Effects (9+)

- `hover:ch-border-ltr` *(left-to-right)*
- `hover:ch-border-wave`
- `hover:ch-border-dashed`
- `hover:ch-border-shimmer`
- `hover:ch-border-radius`
